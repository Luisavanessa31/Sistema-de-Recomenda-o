# Sistema de Recomendação

com PySpark e deploy em Streamlit

📝 Descrição

Desenvolvimento de um sistema de recomendação baseado em filtragem colaborativa, utilizando PySpark ALS e deploy de dashboard interativo com Streamlit.
🛠️ Tecnologias

Streamlit

📂 Estrutura

recommendation-system/
 ├── src/
 │   ├── train_model.py
 │   └── app.py
 ├── data/
 ├── models/
 └── README.md


🚀 Como executar

streamlit run src/app.py

✅ Resultado

Dashboard interativo para recomendações em tempo real.
